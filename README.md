# 🚗 Smart Garage Parking System (ESP8266 / C++)

Смарт-система ультразвукового паркувального асистента для гаража на базі мікроконтролера **Wemos D1 mini (ESP8266)**. Пристрій у реальному часі вимірює відстань до автомобіля, надаючи візуальну (RGB LED) та звукову (Buzzer) індикацію безпечної дистанції, а також транслює дані у `Serial Monitor`.

---

## 📌 Особливості проєкту

* **Динамічний вимірювач відстані:** точне визначення дистанції від 2 см до 400 см за допомогою ультразвукового датчика **HC-SR04**.
* **Трьохрівнева світлова індикація (RGB LED):**
  * 🟢 **Зелений (Safe):** відстань > 50 см — безпечний заїзд.
  * 🟡 **Жовтий (Warning):** відстань від 20 см до 50 см — необхідна уважність.
  * 🔴 **Червоний + Звук (Danger):** відстань < 20 см — зупинка (звуковий сигнал 600 Гц).
* **Апаратна оптимізація під ESP8266:**
  * Усунено конфлікти з boot-пінами (`D3`, `D8`), що забезпечує **стабільне завантаження прошивки "по повітрю / по USB" без необхідності від'єднувати дроти**.
  * Використано піни з підтримкою Hardware Timers для коректної роботи функції `tone()`.

---

## 🛠️ Компоненти та розпіновка (Pinout)

### Необхідні деталі:
1. **Wemos D1 mini** (ESP8266) — 1 шт.
2. **HC-SR04** (Ультразвуковий датчик відстані) — 1 шт.
3. **RGB LED** (із спільним катодом/анодом) + обмежувальні резистори — 1 шт.
4. **П'єзопищалка (Buzzer)** — 1 шт.
5. Макетна плата (Breadboard) та з'єднувальні дроти Dupot.

### Схема підключення:

| Компонент | Пін на модулі | Пін Wemos D1 mini | GPIO (ESP8266) | Примітка |
| :--- | :--- | :--- | :--- | :--- |
| **HC-SR04** | `TRIG` | **D5** | GPIO14 | Імпульс запуску |
| | `ECHO` | **D6** | GPIO12 | Ехо-імпульс |
| | `VCC` | **5V / VIN** | 5V | **Важливо:** 5V для стабільної роботи HC-SR04 |
| | `GND` | **GND** | GND | Спільний мінус |
| **RGB LED** | `Red (R)` | **D1** | GPIO5 | Безпечний пін при завантаженні |
| | `Green (G)`| **D4** | GPIO2 | Сигнальний світлодіод |
| | `Blue (B)` | **D0** | GPIO16 | Цифровий вихід |
| | `GND` | **GND** | GND | Через резистори (220 Ом) |
| **Buzzer** | `Signal` | **D7** | GPIO13 | **Підтримує `tone()`** |
| | `GND` | **GND** | GND | - |
